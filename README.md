# Rigged Basketball
Move the hoop left and right to assist your terrible teammates and get a high score!

## Controls:
Left arrow to move left, right arrow to move right. Game supports keyboard, controller, and mobile

## Description:
You play as a basketball player using a remote to move the hoop. Your goal is to catch as many basketballs as you can without dropping any, as the thrower speeds up over time.

The game features a global leaderboard, allowing you to compete against others in getting higher and higher scores.
